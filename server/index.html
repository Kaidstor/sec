sec://share

одноразовые зашифрованные ссылки

Сюда попадают по ссылкам вида /s/<id>#<ключ>. Их создаёт CLI sec командой sec share.

  1. Шифрование у отправителя sec шифрует секрет локально, на сервер уходит только шифротекст.
  2. Ключ во фрагменте ссылки Часть после # браузер серверу не отправляет: ключа здесь нет ни в базе, ни в логах.
  3. Расшифровка у получателя Страница расшифровывает секрет в браузере. Ссылка сгорает при первом открытии или по сроку.
ссылки создают только владельцы токенов этого сервера
