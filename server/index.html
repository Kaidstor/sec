sec.

одноразовые зашифрованные ссылки

Сюда попадают по ссылкам вида /s/<id>#<ключ> — их создаёт CLI sec командой sec share.

Секрет шифруется на машине отправителя, сервер хранит только шифротекст. Ключ расшифровки живёт во фрагменте ссылки и серверу не отправляется — расшифровка происходит в браузере получателя. Ссылка сгорает при первом открытии или по истечении срока.

zero-knowledge · только для ссылок, созданных владельцами токенов
